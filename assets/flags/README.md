# Language flags

Local SVG flags from [FlagCDN](https://flagcdn.com/), retrieved 2026-11-19.
They are served from this repository; opening the picker makes no flag requests
to a third party. Country associations are illustrative language-picker cues;
language names and searchable English/Russian names remain the primary labels.

The catalog is `js/languages.js`, copied in full from the Mini App's 56
`AUTO_TRANSLATE_LANGUAGE_OPTIONS` entries. EN/RU are native translations. Some
languages share a country flag. Local SVGs avoid Windows rendering flag emojis as
two-letter country codes.
